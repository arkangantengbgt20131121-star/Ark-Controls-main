    Mulai Cepat

    1. Unggah (flash) program MicroPython ke micro:bit agar bisa berkomunikasi lewat Bluetooth. Buka bagian Contoh Kode untuk program yang bisa digunakan.
    2. Buka halaman ini dengan Chrome, Edge, atau Opera. Halaman harus memakai HTTPS atau dibuka dari localhost (server lokal di perangkatmu).
    3. Klik Hubungkan ke Micro:bit, lalu pilih micro:bit dari daftar. Setelah terhubung, data akan tampil dan kamu bisa mengirim perintah.
    4. Belum punya micro:bit? Klik Mode Demo untuk mencoba panel. Pengaturan lainnya ada di menu Pengaturan.

    Fitur yang Bisa Digunakan

    Alarm suhu

    Alarm berbunyi dan kartu suhu berkedip merah jika suhu melewati batas yang kamu atur. Alarm berhenti saat suhu turun sedikit di bawah batas itu. Klik Uji bunyi untuk memastikan suara perangkatmu berfungsi.

    Merekam dan mengunduh data (CSV)

    Data akan direkam otomatis bersama waktu pencatatannya. Klik Export CSV untuk mengunduhnya, lalu buka file tersebut di Excel atau Google Sheets.

    Sambung ulang otomatis dan data terlambat

    Jika koneksi terputus, panel akan mencoba menyambung lagi bila Auto-reconnect diaktifkan di Pengaturan. Jika data tidak diperbarui selama lebih dari 5 detik, data akan ditandai BASI.

    Kipas otomatis

    Panel dapat mengatur kecepatan kipas berdasarkan suhu dan dua batas suhu yang kamu tentukan. Jika kamu mengubah slider kipas sendiri, pengaturan otomatis akan mati.

    Statistik, gamepad, dan notifikasi

    Panel menghitung suhu minimum, maksimum, dan rata-rata selama sesi berjalan—berguna untuk laporan praktikum. Kamu juga bisa mengendalikan robot dengan gamepad USB. Notifikasi alarm tetap muncul saat tab ini tidak sedang dibuka.

    Format Data

    Micro:bit dan halaman web bertukar pesan dalam bentuk teks. Tanda titik dua (:) memisahkan nama data dari nilainya. Setiap pesan dikirim pada baris baru.

    micro:bit → Web

    Program di micro:bit mengirim data berikut agar bisa ditampilkan di halaman ini:

    KunciArtiContoh
    suhuSuhu dalam derajat Celsius (°C)suhu:27.5
    kelembabanKelembapan dalam persen (0–100%)kelembaban:63
    modeNomor mode yang sedang digunakanmode:1
    lampuStatus lampu: 1 berarti menyala, 0 berarti matilampu:1
    kipasKecepatan kipas, dari 0 (mati) hingga 1023 (paling cepat)kipas:512

    Web → micro:bit

    Perintah berikut dikirim saat kamu memakai kontrol di halaman web:

    PerintahArti
    lampu:1 / lampu:0Nyalakan atau matikan lampu
    kipas:0 … kipas:1023Atur kecepatan kipas; angka yang lebih besar berarti kipas lebih cepat
    atas / bawah / kiri / kananGerakkan robot ke arah tersebut selama tombol ditekan
    stopHentikan gerakan saat tombol dilepas

    Contoh Kode

    Program MicroPython untuk micro:bit — buka, salin, lalu unggah 
    # micro:bit - MicroPython (cocok dengan panel ini)
# Flash lewat https://python.microbit.org lalu hubungkan dari panel ini
from microbit import *
import bluetooth

ble = bluetooth.BLE()
uart = bluetooth.UART()
buf = ""

def kirim(baris):
    uart.write(baris + "\n")

# Terima perintah dari Web
def tangani(cmd):
    if cmd == "lampu:1":
        pin0.write_digital(1)
        kirim("lampu:1")
        display.show(Image.YES)
    elif cmd == "lampu:0":
        pin0.write_digital(0)
        kirim("lampu:0")
        display.show(Image.NO)
    elif cmd.startswith("kipas:"):
        try:
            v = max(0, min(1023, int(cmd[6:])))
        except ValueError:
            v = 0
        pin1.write_analog(v)
        kirim("kipas:" + str(v))
    elif cmd == "atas":
        display.show(Image.ARROW_N)
    elif cmd == "bawah":
        display.show(Image.ARROW_S)
    elif cmd == "kiri":
        display.show(Image.ARROW_W)
    elif cmd == "kanan":
        display.show(Image.ARROW_E)
    elif cmd == "stop":
        display.clear()

while True:
    if uart.any():
        buf += str(uart.read(), "utf-8")
        while "\n" in buf:
            baris, buf = buf.split("\n", 1)
            if baris.strip():
                tangani(baris.strip())
    # Kirim data sensor ke Web tiap 1 detik
    kirim("suhu:" + str(temperature()))
    # micro:bit tidak punya sensor kelembaban bawaan -
    # ganti dengan sensor eksternal (mis. DHT11)
    kirim("kelembaban:60")
    kirim("mode:1")
    sleep(1000)

    Bantuan

    Tombol hubungkan error / tidak bisa diklik

    Coba gunakan Chrome, Edge, atau Opera versi terbaru. Pastikan halaman dibuka lewat HTTPS atau localhost, lalu nyalakan Bluetooth di perangkatmu.

    Perangkat tidak muncul

    Dekatkan micro:bit hingga sekitar 2 meter. Pastikan program yang memakai bluetooth.UART() sudah diunggah dan micro:bit tidak sedang terhubung ke perangkat lain.

    Data tidak masuk

    Periksa apakah setiap pesan mengikuti format kunci:nilai, lalu diakhiri dengan \n (pindah ke baris baru). Nama kunci dan contoh nilainya ada di tabel Format Data.

    Koneksi sering terputus

    Matikan lalu nyalakan kembali Bluetooth. Jika micro:bit pernah dipasangkan lewat pengaturan Bluetooth perangkatmu, hapus pasangan itu lalu coba hubungkan lagi dari halaman ini. Kamu juga bisa mengaktifkan Auto-reconnect di Pengaturan.

    Koneksi Bluetooth didukung di Chrome, Edge, dan Opera. Firefox dan Safari belum mendukungnya; gunakan Mode Demo di browser tersebut.

    Koneksi Bluetooth

    Auto-reconnect Sambung ulang otomatis jika putus tiba-tiba.
    Jaga layar menyala Cegah layar mati saat terhubung / demo (monitoring lama).
    Upaya maksimum 1–20 upaya sebelum berhenti.
    Prefiks nama perangkat Filter saat memilih perangkat.
    UUID service Berlaku untuk koneksi berikutnya. Karakteristik tetap terdeteksi otomatis.

    Impor pengaturan Pulihkan dari file JSON.
    Kembalikan default Hapus semua pengaturan tersimpan & muat ulang halaman. Koneksi akan terputus.
